# 運営者だけを管理者に指定する

新規登録したユーザーは、最初の登録者も含めて全員が一般ユーザーになります。
登録画面・URL・ニックネーム・メールアドレスの一致で管理者になることはありません。
サーバーのターミナルを操作できる運営者が、確認したアカウントのIDを使って指定します。
有料サービス、メール送信、APIキーは不要です。

## 氏名・電話番号なしで運営用アカウントを新しく作る

PowerShellで `C:\Users\user\camp\python\help-rate` を作業フォルダにして実行します。

```powershell
.\.venv\Scripts\python.exe -m flask --app .\help-rate\app.py admin create
```

- 入力するのは運営用ログイン名とパスワードだけです。氏名・電話番号・住所・生年月日は不要です。
- 運営用ログイン名は本名でなくて構いません。既存ユーザーのニックネーム・メール・電話番号と同じ値は使えません。
- パスワードは15〜64文字です。英数字の混在は必須ではありません。推測されにくい、長めで使い回さないものを決めてください。
- パスワードは伏せて入力し、確認のためもう一度入力します。チャットやコマンドの引数には書かないでください。
- 最後にログイン名を確認して `y` を入力すると、管理者として作成されます。
- 作成後は通常のログイン画面を使います。ログインID欄に運営用ログイン名を入力してください。
- パスワードはハッシュ化して保存し、入力した文字そのものや確認用の入力は保存しません。

この作成手順はサーバーのターミナル限定です。公開の登録画面には管理者用の入力項目を追加しません。
一般ユーザーの登録条件（6〜20文字）と、既存アカウントのパスワードは変わりません。

## 既存アカウントの権限を変更する（Windows PowerShell）

`C:\Users\user\camp\python\help-rate` を作業フォルダにします。

1. 運営者自身が通常の登録画面でアカウントを作成します。
2. 次のコマンドでIDとニックネームを確認します。最初の登録者を自動的に選ばず、運営者本人のアカウントを特定してください。

```powershell
.\.venv\Scripts\python.exe -m flask --app .\help-rate\app.py admin list
```

3. 次の `USER_ID` を確認した数字に置き換えます。確認画面に表示されるIDとニックネームが本人のものなら、`y` を入力します。

```powershell
.\.venv\Scripts\python.exe -m flask --app .\help-rate\app.py admin grant USER_ID
```

4. 権限を解除する場合は、対象を確認して次を実行します。

```powershell
.\.venv\Scripts\python.exe -m flask --app .\help-rate\app.py admin revoke USER_ID
```

権限変更は次のリクエストから反映されます。画面を再読み込みしてください。
データベースは作業フォルダによらず `help-rate/helprate.db` が対象です。
コード更新後は、アプリを再起動してから運用してください。

## 管理者がパスワードを忘れた場合

PowerShellで次の1行を実行します。作業フォルダが `C:\Windows\system32` でも使えます。

```powershell
& "C:\Users\user\camp\python\help-rate\.venv\Scripts\python.exe" -m flask --app "C:\Users\user\camp\python\help-rate\help-rate\app.py" admin reset-password
```

1. 再設定する運営用ログイン名を入力します。
2. 表示されたIDとログイン名が対象の管理者であることを確認し、`y` を入力します。
3. 新しいパスワード（15〜64文字）を2回入力します。入力した文字は表示されません。
4. 完了したら、通常のログイン画面で新しいパスワードを使います。

元のパスワードやメール・電話番号は不要です。ユーザー情報・権限・依頼・チャットは削除しません。
一般ユーザーや存在しないアカウントは、このコマンドでは変更できません。
パスワードはコマンドの引数やチャットに書かず、入力案内が出てから入力してください。
サーバーの端末を操作できる運営者だけが使う機能で、公開の再設定ページは追加しません。

## 旧バージョンからの変更

起動時の移行処理は、最初の登録者への自動付与を含め、運営者による指定の記録がない管理者権限を解除します。
ユーザー・依頼・チャットなどのデータは削除しません。
専用コマンドで明示的に指定した権限は、再起動後も保持されます。
旧データベースにも、切り替えて使う前に同じ移行処理が必要です。

サーバーの操作権限やデータベースファイルは、運営者以外に渡さないでください。
