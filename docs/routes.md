# ルーティング設計: おらほの助っ人けっぱれーと

Flaskアプリケーション（`app.py`）で設定するURLと、対応する処理の一覧です。

| HTTPメソッド | URLパス | 対応する関数名（例） | ログイン要否 | 役割・説明 |
| :--- | :--- | :--- | :--- | :--- |
| **GET** | `/login` | `login()` | 不要 | **ログイン画面**を表示する |
| **POST** | `/login` | `login_post()` | 不要 | 入力された認証情報を検証し、ログイン処理を行って一覧画面へリダイレクトする |
| **GET** | `/register` | `register()` | 不要 | **ユーザー登録画面**を表示する |
| **POST** | `/register` | `register_post()` | 不要 | 新規ユーザー情報をデータベースに保存し、ログイン画面へ誘導する |
| **GET** | `/` | `index()` | 不要 | **投稿一覧（トップ）画面**を表示する（全案件をデータベースから取得） |
| **GET** | `/post` | `post_create()` | 必要 | **投稿作成画面**（フォーム）を表示する |
| **POST** | `/post` | `post_create_submit()` | 必要 | 入力された案件データをデータベースに保存し、一覧画面へリダイレクトする |
| **GET** | `/task/<int:task_id>` | `task_detail(task_id)` | 必要 | 該当するIDの**投稿詳細画面**を表示する |
| **POST** | `/task/<int:task_id>/apply` | `task_apply(task_id)` | 必要 | 「このお手伝いをする」ボタンが押されたときの応募処理を行う |
| **POST** | `/task/<int:task_id>/edit` | `task_edit(task_id)` | 必要 | 自分の投稿を編集・更新する処理を行う |
| **GET** | `/logout` | `logout()` | 必要 | ログアウト処理を行い、一覧画面へリダイレクトする |
