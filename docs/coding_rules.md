# コーディング規約・実装ルール

1. **日本語コメントの徹底**
   - 初学者の学習用として、関数や主要な処理には分かりやすい日本語コメントを必ず記載する。
2. **エラーハンドリングの簡潔化**
   - 複雑な例外処理は避け、初学者が読み通せるシンプルなコード構成を維持する。
3. **セキュリティの基本**
   - パスワード等の機密情報はコードに直書きせず、`.env` から読み込む。
   - フォームには必ず Flask-WTF による CSRF 対策を施す。
4. **ファイル保存のルール**
   - ユーザーがアップロードする画像ファイルは、必ずプロジェクト直下の `uploads/` フォルダに保存・参照する。
