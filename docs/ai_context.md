# アプリケーション概要: おらほの助っ人けっぱれーと

## 1. 目的・ターゲット
- 岩手県平泉町などを想定した、地域密着型のお手伝いマッチングWebアプリ。
- スマートフォンやPCの操作が苦手なお年寄りの代わりに、身近な人が「代理投稿」でき、地域の助っ人（ボランティア）とマッチングする。

## 2. 技術スタック
- **言語:** Python (3.13)
- **Webフレームワーク:** Flask
- **ORM / DB:** Peewee + SQLite
- **認証・セキュリティ:** Flask-Login, Flask-WTF (CSRF対策), email-validator
- **環境変数管理:** python-dotenv

## 3. ディレクトリ構造・画像保存先
- プロジェクト直下の `uploads/` フォルダを、ユーザー投稿画像の保存先として使用する。
- テンプレートは `templates/`、静的ファイルは `static/` に配置する。
