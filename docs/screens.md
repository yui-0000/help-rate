# 画面設計: おらほの助っ人けっぱれーと

## 画面一覧
1. ログイン画面 (`/login`)
2. ユーザー登録画面 (`/register`)
3. 投稿一覧（トップ）画面 (`/`)
4. 投稿作成画面 (`/post`)
5. 投稿詳細画面 (`/task/<int:task_id>`)

---

## 各画面の詳細

### 1. ログイン画面
- **URL:** `/login`
- **目的:** アプリを利用する前に、ユーザー名とパスワードを入力してログインする。
- **ログインが必要か:** 不要（誰でもアクセス可能）
- **使用するテンプレート:** `login.html`
- **主な部品:**
  - ユーザー名・パスワードの入力欄
  - 「ログイン」ボタン
  - 「新規アカウント登録はこちら」へのリンク
- **画面遷移:** ログイン成功後 → **投稿一覧（トップ）画面**へ

### 2. ユーザー登録画面
- **URL:** `/register`
- **目的:** 新規のユーザー（代理投稿者や助っ人）としてアカウントを作成する。
- **ログインが必要か:** 不要
- **使用するテンプレート:** `register.html`
- **主な部品:**
  - ユーザー名・メールアドレス・パスワードの入力欄
  - 立場（代理の人、助っ人など）の選択肢
  - 「登録する」ボタン
- **画面遷移:** 登録成功後 → **ログイン画面**へ

### 3. 投稿一覧（トップ）画面
- **URL:** `/`
- **目的:** 地域に投稿されたすべての困りごとを確認する、アプリのメイン画面。
- **ログインが必要か:** 不要（閲覧のみなら誰でも可能）
- **使用するテンプレート:** `index.html`
- **主な部品:**
  - ヘッダー（現在ログイン中のユーザー名、「投稿する」ボタン、「ログアウト」ボタン、ログイン/登録へのリンク）
  - 困りごと案件のカードリスト（タイトル、種類、お礼などを表示）
  - 各カードにある「詳細を見る」ボタン
- **画面遷移:**
  - 「投稿する」ボタン → **投稿作成画面**へ
  - 各カードの「詳細を見る」ボタン → **投稿詳細画面**へ

### 4. 投稿作成画面
- **URL:** `/post`
- **目的:** 新しい困りごとやお手伝いをお願いしたい内容を入力して登録する。
- **ログインが必要か:** 必要
- **使用するテンプレート:** `post.html`
- **主な部品:**
  - 入力フォーム（タイトル、困りごとの種類、詳しい内容、お礼など）
  - 「投稿する」ボタン
- **画面遷移:** 投稿送信成功後 → **投稿一覧（トップ）画面**へ戻る

### 5. 投稿詳細画面
- **URL:** `/task/<int:task_id>`
- **目的:** 案件の詳しい内容を確認し、応募したり、自分が投稿したものであれば編集・削除を行ったりする。
- **ログインが必要か:** 必要
- **使用するテンプレート:** `detail.html`
- **主な部品:**
  - 案件の詳しい情報（タイトル、投稿者、内容、お礼）
  - アクションボタン：
    - 他人の案件の場合：「このお手伝いをする（決定）」ボタン
    - 自分の案件の場合：「編集する」「削除する」ボタン
  - 「一覧に戻る」リンク
- **画面遷移:** 応募や編集の処理完了後 → **投稿一覧（トップ）画面**または詳細画面を再表示
