# 管理者のデータ確認と一般ユーザーの削除

管理者でログインすると、ホームの「ユーザー情報を見る」「削除済みデータを見る」から管理画面へ進めます。追加の有料サービスは使いません。

- ユーザーの登録済みの氏名・電話番号などを確認できます。パスワードは表示しません。住所・生年月日は現在のユーザー登録では収集していません。
- 一般ユーザーの詳細画面から削除確認へ進み、対象のニックネームを入力して削除します。管理者・運営用アカウントは削除できません。
- 削除されたユーザーは、既にログインしていたブラウザでも利用できなくなります。本人の依頼・送信したチャットも通常画面から隠れ、他の依頼での助っ人の割り当ては解除されます。
- 削除された依頼、そのチャット・写真、取り消されたチャット、差し替え前の写真は、管理者だけが確認できます。写真のURLからも一般利用者には公開されません。
- 削除・差し替えから90日間保管し、期限を過ぎたものは管理画面にも表示しません。既に削除した記録を再操作しても期限は延長しません。
- 期限切れの記録と写真は、アプリへの最初のアクセス時、その後はアクセス時に最大1分間隔で消去します。アプリ停止中・アクセスがない間は消去処理は動かず、次のアクセスで処理します。写真の消去に失敗した場合は次回に再試行します。
- 管理者・運営用アカウントの登録情報は期限切れ消去の対象にもなりません。現在利用中の一般ユーザーも対象外です。
- 写真は1依頼につき1枚・5MB以内、一覧は20件ずつ表示します。保存先PCの空き容量は必要です。
- 保管日時は内部ではUTC、管理画面では日本時間で表示します。公開投稿の日時や内容は変更しません。

過去に完全削除されたデータは復元できません。今回の変更後に削除・差し替えされたデータが対象です。復元ボタンはありません。
