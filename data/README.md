# 郵便番号の住所入力補助

出典：日本郵便「住所の郵便番号（1レコード1行、UTF-8形式）」
https://www.post.japanpost.jp/service/search/zipcode/download/utf-zip.html

取得日：2026-10-17。掲載上の更新日：2026-09-30。
データ配布元：https://www.post.japanpost.jp/service/search/zipcode/download/utf/zip/utf_ken_all.zip

日本郵便は郵便番号データについて著作権を主張せず、自由な再配布を認めています。
https://www.post.japanpost.jp/service/search/zipcode/download/utf-readme.html

utf_ken_all.zip は配布元のCSV ZIPをそのまま保存しています。更新時は配布元からこのファイルを差し替え、アプリを再起動してください。自動更新は行いません。

郵便番号検索はアプリ内で行い、APIキー・課金契約・外部への利用者情報の送信は不要です。一般の町域郵便番号が対象で、事業所個別郵便番号は含みません。郵便番号は町域までの補助入力で、番地・建物名・部屋番号の実在は確認できません。同じ郵便番号の候補が複数ある場合は利用者が選択します。町域の括弧内の範囲説明は入力住所から除外します。見つからない場合やJavaScript無効時にも住所の手入力は可能です。
